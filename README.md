# Enterprise AI Knowledge & Operations Copilot

Production-oriented AI engineering project based on the supplied project plan.

## Planned stack
- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Python, FastAPI, Pydantic, SQLAlchemy
- AI: LLM APIs / open-source models, LangChain, LangGraph
- RAG: embeddings, vector search, hybrid retrieval, reranking, query rewriting
- Database: PostgreSQL + pgvector
- Infrastructure: Docker, Docker Compose, GitHub Actions
- Observability: OpenTelemetry and LLM tracing/evaluation

## Repository status
This repository currently contains the complete project structure and configuration placeholders only.
Application implementation will be added incrementally; no application code is included in this foundation package.
